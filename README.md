# Hotel Rush

3D-игра про администратора отеля для телефона (PWA). Заселяй гостей в номера нужного типа, оформляй выезды, отправляй горничных и техника, отвечай на вопросы гостей. Карьера по дням с целью на смену, улучшения отеля, VIP-гости, жалобы и ночные смены.

Играть: https://kzkv274.github.io/HotelRush/

- 3D: [three.js](https://threejs.org) 0.170 (загружается с cdn.jsdelivr.net)
- Модели: [Kenney Mini Characters](https://kenney.nl/assets/mini-characters) и [Kenney Furniture Kit](https://kenney.nl/assets/furniture-kit), лицензия CC0
- Прогресс хранится на телефоне (localStorage)
